# gamehub (paquete Python)

Herramientas de GameHub en Python. Estado: **Fase 0** — validación de la GameIR v0.

```bash
uv sync                                         # entorno de desarrollo
uv run gamehub ir check ../spec/ir/examples/*.ir.json
uv run gamehub ir schemas --check               # esquemas generados al día
uv run pytest
```
